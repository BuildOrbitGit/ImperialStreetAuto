## Remaining Issues

**[P2] Specials card dark glow**
- **What**: `box-shadow` with `rgba(200,30,30)` and similar red-tinted glows on a dark card background (line 670+). Three near-identical dark reds (`#b01a1a`, `#c82020`, `#a01616`) drive hover states on the same element.
- **Why it matters**: The colored glow on dark bg is the "saturated AI default cool look" tell the detector flags. It's the one remaining element that reads as generated rather than chosen. Three reds doing the same job is also unnecessary drift.
- **Fix**: Replace the colored glow with a subtle border or background shift on hover. Consolidate the three reds to one token. The specials card can still be bold without the glow — a red border-top band or a solid red bg on the header achieves confidence without the SaaS tell.
- **Suggested command**: `/impeccable polish index.html`

**[P2] No skip-to-content link**
- **What**: Keyboard users tab through 15+ nav items before reaching any content. No `<a href="#main" class="skip-link">` exists.
- **Why it matters**: Sam using keyboard navigation has to tab through the entire utility bar, nav links, and hero before reaching any content section. This is a WCAG 2.1 AA failure (Criterion 2.4.1).
- **Fix**: Add a visually hidden skip link as the first child of `<body>`: `<a href="#main" class="skip-link">Skip to content</a>` with CSS that shows it on focus. Add `id="main"` to the first content section or the `<main>` element.
- **Suggested command**: `/impeccable audit index.html`

**[P3] ARIA landmarks missing**
- **What**: No `<main>`, `<header>`, `<footer>`, or `<nav role="navigation">` elements (or all content is in generic divs without role attributes).
- **Why it matters**: Screen reader users navigating by landmark jump around efficiently. Without landmarks, the page is a flat list of content.
- **Fix**: Wrap nav in `<header>`, content sections in `<main>`, and footer in `<footer>`.
- **Suggested command**: `/impeccable audit index.html`

**[P3] Specials card coloured reds need tokenising**
- **What**: `#b01a1a`, `#c82020`, `#a01616` at line 681 — three near-identical dark reds, none documented in DESIGN.md.
- **Fix**: Pick one (suggest `#c82020`) as `--danger-deep`, add to DESIGN.md, replace the other two.
- **Suggested command**: `/impeccable polish index.html`
